# Торговый прилавок — 1.3.0

Крафт: пять досок и палка. Поставить над сундуком или бочкой. Запас остаётся в настоящем контейнере: прилавок не даёт бесплатного виртуального склада.

## Игроку

Владелец назначается при установке. Образец во второй руке, основная пустая: обычный ПКМ выбирает товар. Поддерживаются обычные предметы; имена, чары и содержимое контейнеров пока явно отклоняются. Пустые руки + ПКМ открывают окно. Владелец вводит цену за партию или за штуку (итог 1–30000) и размер партии числом (1–64). Посетитель покупает одну партию. Продавец может быть офлайн.

Перед оплатой проверяются расстояние, существование блока, неизменность предложения, запас и место в инвентаре. Изменение цены/товара требует открыть окно заново. Предметы не выбрасываются на землю при переполнении.

## Защита и нагрузка

У блока нет ticker, таймеров и фонового HTTP-опроса. Остаток считается при открытии/действии, не каждый тик. Окно использует штатную синхронизацию меню Minecraft. Клиент рисует один образец в пределах 24 блоков. Журнал записывается по событию продажи; дисковые записи с подтверждением относятся к стоимости сделки, а не к постоянному тику.

Carry On: штатный тег data/carryon/tags/block/block_blacklist.json; Shift не используется для настройки. OPAC 0.29.3: точечная обработка публичного пустого ПКМ прилавка; настройка владельцем проверяется через API onEntityPlaceBlock. Защита сундука, установки и разрушения в привате сохраняется. При незавершённой сделке обычное разрушение прилавка дополнительно блокируется. Перенос Create/Sable в ходе сделки не проверен.

## Оплата и восстановление

Новый сайт-эндпоинт crystals_stall_api.php использует общий CrystalStalls.php и существующие users.crystals. Подключение — прежний apiBaseUrl/apiSecret в config/Xs_Crystal/config.json. Авторизация — отдельный ключ хрусталиков и существующий firewall crystals-listing. Таблица crystal_stall_trades хранит резерв и итог.

reserve: уникальный tx_id блокируется до списания денег, запрос привязан к неизменному хешу. commit: после выдачи товара продавцу начисляется цена за вычетом действующей комиссии сайта. refund: только отмена до выдачи. Все повторы идемпотентны. Ошибка хоста/невалидный ответ считаются неизвестным исходом; используется прежний tx_id.

Локальный журнал мира data/crystal-stall-transactions сохраняет участников, товар, координаты, сумму и фазу операции. Фаза applying после аварии требует ручной сверки; автоматической повторной выдачи и возврата нет. Сохранение инвентаря игрока и чанка Minecraft не является одной транзакцией с БД: аппаратный сбой в этот момент требует проверки. Журнал не удалять вслепую.

## Проверка

Настоящий клиент NeoForge 21.1.252, OPAC 0.29.3, Carry On 2.2.6.13; полная копия из 139 модов без DobbyMod. Продажа 8 железных слитков за 10 хрусталиков: бочка 64→56, инвентарь +8, продавцу +9, комиссия 1. Проверены двойной клик, полный инвентарь, устаревшая цена, возврат при закрытии окна, конкурентные повторы API и отклонение индивидуальных компонентов.

Сценарии src/testClient включаются только -PstallTest. Обычный jar их не содержит. Подробности, конфиг локального API, логи и пять скриншотов: VPS-Server-Minecraft/lab-local/STALL_MARKET_LAB.md. Прод и основной клиент не менялись.

## Магазины на сайте

Добровольная заявка на сайте /market/shops или /crystal shop apply "Название" Специализация. /crystal shop list показывает ID и статус; /crystal shop link ID привязывает прилавок под взглядом, ID 0 снимает привязку. Название, специализацию и оформление проверяет модератор; зарегистрированная карточка остаётся публичной до проверки изменений. Прилавки работают без регистрации и после её приостановки.

StallShops отправляет асинхронные снимки каталога по взаимодействиям, не чаще раза в 15 секунд; фонового HTTP-опроса и ticker нет. На сайте отображается время снимка. Работающие механизмы могут пополнять бочку/сундук под блоком: повторные продажи после подачи воронкой проверены. Прямое чтение Create Item Vault не добавлено. При выпуске 1.3.0 обновлять сервер и клиент вместе: обязательный сетевой протокол 2.

Сайт: CrystalShops.php, crystal_shops_api.php, market_shops.php, docs/CRYSTAL_SHOPS.md. Проверки — native HTTP, браузер (подача/одобрение) и настоящий Minecraft-клиент; исходники игровых сценариев остаются только в src/testClient.
